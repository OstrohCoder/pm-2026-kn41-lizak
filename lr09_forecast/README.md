## 2. Як рахувалася симуляція

| Поле | Значення |
| --- | --- |
| Інструмент | власний скрипт Python |
| Прогонів | 10000 |
| Що тягнеться випадково | velocity одного з моїх спринтів (18 або 15) |
| Як рахується дата прогнозу | останній день спринта, на якому закінчується робота: для сценарію «весь перший реліз» кінець спринта 1 плюс (P − 1) × 14 днів, для сценарію залишку кінець останнього спринта плюс P × 14 днів |

```python
import random, math

def simulate(remaining, velocities, n=10000, seed=42):
    rnd = random.Random(seed)
    results = []
    for _ in range(n):
        left, sprints = remaining, 0
        while left > 0:
            left -= rnd.choice(velocities)
            sprints += 1
        results.append(sprints)
    results.sort()
    pct = lambda p: results[math.ceil(p * n) - 1]
    return pct(0.5), pct(0.85)

print(simulate(61, [18, 15]))   # весь перший реліз
print(simulate(28, [18, 15]))   # залишок після двох спринтів
```
